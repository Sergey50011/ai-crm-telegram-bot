## Проект

**AI-ассистент для записи клиентов (Telegram-бот автосервиса)**

- Приём заявок в свободной форме, разбор полей через LLM (OpenRouter).
- Подтверждение, дедуп по телефону за 24 ч, админ в Telegram и веб-панель (Flask + SQLite).

**Стек:** Python, aiogram, aiosqlite, OpenRouter, Pydantic, Flask.
